# G5 – Operating Systems, Networks, Databases

## Target

- Exam score: **80–95%**.

## Operating Systems

- [ ] Processes, threads, and their states.
- [ ] CPU scheduling algorithms.
- [ ] Synchronisation (critical section, semaphores, monitors).
- [ ] Deadlocks (detection, prevention, avoidance).
- [ ] Memory management and paging.
- [ ] File systems and I/O basics.

## Computer Networks

- [ ] Layered models (OSI, TCP/IP).
- [ ] Application layer protocols (HTTP, DNS, etc.).
- [ ] Transport layer (TCP, UDP, congestion control basics).
- [ ] Network layer (IP, routing, subnetting).
- [ ] Link layer and basic wireless concepts.

## Databases

- [ ] ER modelling.
- [ ] Relational model and relational algebra.
- [ ] SQL queries (selection, joins, aggregation, subqueries).
- [ ] Normal forms (1NF–3NF, BCNF).
- [ ] Transactions and basic concurrency concepts.
